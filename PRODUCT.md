## Platform

web

## Product Purpose

A rental homes interface for both landlords and renters, as requested by the user.

## Capabilities and Constraints

Use the existing Next.js project and Tailwind. UI only, without a backend or database. Use the industrial-brutalist-ui skill for a modern interface. Sample properties, people, and financial figures are illustrative. State is held in memory and resets on refresh.

Light and dark themes are available throughout both workspaces. Theme preference is saved locally across refreshes; without a saved preference, use the system theme.

## Users

Landlords manage homes; renters browse homes. Detailed workflows and the FORME name are implementation assumptions.
